Abishek M - Portfolio
=====================
Open index.html in any browser to view the site.
It is a single self-contained file (photo included). Fonts load from Google Fonts when online.

To put it online for free:
- Vercel: drag this folder into vercel.com/new, or run "vercel" inside it.
- Netlify: drag this folder onto app.netlify.com/drop.
- GitHub Pages: push index.html to a repo and enable Pages.
